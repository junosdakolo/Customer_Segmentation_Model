# Customer Segmentation Model

This project is focused on developing a machine learning model for customer segmentation using various features. The goal is to analyze customer behavior, predict their likelihood to subscribe to a service, and provide actionable insights for business strategies.

## Features

- **Promo Code Used**: Whether the customer used a promo code (Yes/No).
- **Discount Applied**: Whether a discount was applied (Yes/No).
- **Purchase Amount (USD)**: The amount spent by the customer.
- **Previous Purchases**: The number of previous purchases by the customer.
- **Review Rating**: The customer's rating for the product purchased.
- **Cluster**: The customer’s segment or cluster.

## Machine Learning Models

- **Logistic Regression**
- **Random Forest Classifier**
- **Gradient Boosting**

The models show varying levels of performance based on different features and tuning parameters. The Random Forest and Gradient Boosting models were the most effective for this dataset.
